# InfuseTax Brand Kit

Generated from the supplied InfuseTax logo.

## Structure
- web/       Website header logos, responsive sizes, wordmark
- favicon/   Browser favicon PNGs + favicon.ico
- app/       Mobile/app icon sizes + SVG wrapper
- social/    Open Graph, profile, social and app-store style assets
- print/     Highest-resolution supplied-logo exports
- source/    Original crops and transparent separated source assets

## Recommended usage
- Website desktop header: web/infusetax_logo_800x300.png or 600x200.png
- Website mobile header: web/infusetax_logo_300x100.png
- Compact navbar: web/infusetax_wordmark_400x110.png
- Mobile app / PWA icon: app/infusetax_icon_512.png or 1024.png
- Browser favicon: favicon/favicon.ico + favicon_32x32.png
- Apple touch icon: app/infusetax_icon_180.png
- Android/PWA: app/infusetax_icon_192.png and 512.png
- Social profile: social/infusetax_profile_1080x1080.png
- Open Graph / link preview: social/infusetax_og_1200x630.png

## Note
The supplied logo is raster artwork. The SVG files are PNG-embedded SVG wrappers, not a true vector redraw.
For production print/signage, a true vector SVG/AI/PDF redraw is recommended.
